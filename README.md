# Rolax.Resort Hotel Website

Welcome to the **Rolax Resort Hotel** project — a fully responsive, professional hotel booking website built with modern front-end technologies. This project showcases a luxury hotel with its rooms, restaurant, bar, blog, and contact information in a sleek and interactive interface.

---

## 🏨 Project Overview

**Rolax Resort** is a professional hotel booking website designed to provide an immersive and elegant user experience. The website includes the following pages:

- **Home Page** – Showcases the hotel’s amenities, rooms, and gallery with pop-up images.
- **About Page** – Highlights the story, philosophy, and values of the hotel.
- **Rooms Page** – Displays all rooms with descriptions, pricing, and a dedicated **Room Booking Page** for each room.
- **Resto & Bar Page** – Features the restaurant and bar menus with professional layout and images.
- **Blog Page** – Highlights latest news and articles related to the hotel and hospitality.
- **Contact Page** – Includes contact information with an integrated Google Map for easy location access.

The project is fully **front-end ready**, allowing easy integration with any back-end system to handle bookings, payments, or other dynamic functionalities.

---

## ✨ Features

- **Fully Responsive Design** – Works seamlessly on mobile, tablet, and desktop devices.
- **Room Booking** – Each room has a dedicated booking page with detailed descriptions and a fake checkout button for front-end demonstration.
- **Gallery with Pop-up Images** – High-quality images of the hotel’s interiors and amenities.
- **Smooth Animations** – Powered by **Framer Motion** for professional UI transitions.
- **Modern UI Elements** – Includes **React Icons** and **Lucide React** for interactive elements.
- **Restaurant & Bar** – Separate sections for restaurant and bar menus with hover effects.
- **Blog Section** – Latest news and article showcase.
- **Testimonials** – Carousel slider displaying guest reviews.
- **Contact Page** – Includes contact form and embedded Google Map.
